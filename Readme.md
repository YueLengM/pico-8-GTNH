## 功能 Features

- 在 GTNH 里玩各种小游戏 <br> Play mini-games in GTNH
- 游戏内搜索及下载卡带 <br> Browse & download cartridges in game
- 即时存档 / 回放功能 <br> Quick Save/Load
- 支持仅客户端，在没有 Mod 的服务器上可使用指令运行 <br> Support client only mode, starts via commands
